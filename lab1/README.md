# Лабораторна робота №1
## Кубічна сплайн-інтерполяція

### Мета роботи
Побудувати висотний профіль маршруту на Говерлу 
за допомогою натурального кубічного сплайна.

### У роботі виконано:
- Отримано координати та висоти через Open-Elevation API
- Обчислено кумулятивну відстань між точками
- Реалізовано натуральний кубічний сплайн (метод прогонки)
- Побудовано графік профілю маршруту
- Побудовано графік сплайна
- Обчислено та проаналізовано градієнт
- Обчислено механічну енергію підйому
- Визначено похибку інтерполяції

### Результат
Програма будує всі необхідні графіки та виводить основні розрахунки в терміналі.
